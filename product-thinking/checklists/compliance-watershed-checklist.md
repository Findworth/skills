# 合规分水岭预案清单

> **何时用本清单**：当你所在的行业出现"灰色玩法红利期"（NPC、盲盒、剧本杀、AI 内容、IP 周边、擦边直播……）时，**在被官媒点名之前**用本清单做体检。任何新兴行业都会有"被一夜定调"的瞬间——你的任务是让那一刻到来时，你还在桌上。

## 适用对象
- 处于"快速增长但争议不断"赛道的创始人
- 平台型/内容型/IP 衍生品业务的运营负责人
- 法务/PR 应急团队
- 任何业务依赖"用户互动尺度"或"未授权资源"的从业者

---

## 核心心法

> **每个新兴行业都会经历一次"分水岭事件"**——直播带货有过、短视频有过、剧本杀有过、景区 NPC 是"小黄鱼"。
> 一旦官媒定调，行业不会消失，但**互动尺度/玩法边界会被永久压低一格**，"擦边"变成不可承受的成本。
> 提前做预案的人活下来，赌"我们不会被查"的人归零。

---

## 第一部分：监管风险扫描清单（6 类）

### A. IP 与版权风险
- [ ] 我使用的角色形象/IP 是否有官方授权链路（合同/票据/邮件确认）？
- [ ] 我销售的周边商品，是否涉及他人著作权、商标权、外观设计专利？
- [ ] 我用的 AI 生成图，是否可能侵犯训练数据中的原作品？
- [ ] 我的"致敬款""同款""灵感来自"，律师怎么看？

### B. 资质与牌照
- [ ] 我做的内容/服务是否需要 ICP、文网文、出版物经营、医疗广告等许可？
- [ ] 我聘用的人员（主播/演员/导师）是否需要持证上岗？
- [ ] 我跨境/跨平台经营，是否每个司法辖区都有合规备案？

### C. 内容尺度与价值观
- [ ] 我的内容是否可能被定义为"擦边""低俗""炫富""价值观偏差"？
- [ ] 我的互动设计是否依赖暧昧、性暗示、PUA 话术？
- [ ] 假设《人民日报》/《新华社》明天发评论员文章评我们这个品类，会怎么写？

### D. 消费陷阱与诱导
- [ ] 我的定价/抽奖/盲盒机制是否构成"赌博性消费诱导"？
- [ ] 我有没有针对老人、未成年、低收入群体的过度营销？
- [ ] 我的"预售""定金""限时"是否符合《消费者权益保护法》和电商法？

### E. 未成年人保护
- [ ] 我的用户中是否有 < 18 岁参与？参与方式是否合规？
- [ ] 我有没有年龄识别 + 消费限额 + 监护人确认的机制？
- [ ] 我的内容/产品是否可能对未成年人产生不良影响？

### F. 数据与隐私
- [ ] 我收集的用户数据是否有明示授权？
- [ ] 我的私域运营是否符合个保法（标注退出方式、不滥用画像）？
- [ ] 我有没有处理 R18 / 敏感人群数据？

## 第二部分：分水岭预警信号（5 大信号）

出现以下任一信号，**立即启动 24 小时预案**：

- [ ] **信号 1：官媒点名** — 《人民日报》《新华社》《央视》等发评论或调查
- [ ] **信号 2：同行被处罚** — 同品类某玩家被下架/封号/罚款，行业全员紧张
- [ ] **信号 3：用户投诉异常** — 黑猫/12315/微博/小红书出现集中负评
- [ ] **信号 4：平台规则变化** — 抖音/小红书/淘宝突然调整该品类规则
- [ ] **信号 5：监管表态** — 网信办/市监总局/文旅部/广电总局公开表态

### 预警评分（自检）
- 0 个信号：常规期，按月做一次本清单体检
- 1 个信号：黄色警报，本周内开应急会
- 2 个信号：橙色警报，24 小时内启动事中应对
- 3 个及以上：红色警报，**立即停掉所有灰色玩法**

## 第三部分：应对预案模板

### 事前缓冲（红利期就该做的）

- [ ] 准备**白名单玩法**：当擦边玩法被禁后，至少有 3 个"安全替代方案"可顶上（如葛仙村 NPC 从"擦边互动"换成"簪花互动"）
- [ ] 储备**官方背书**：与文化、文旅、教育、非遗等"正面叙事"提前建立连接
- [ ] 留足**现金流缓冲**：能撑住 3-6 个月零收入
- [ ] 团队**多元收入结构**：不能 80% 收入来自一个灰色玩法
- [ ] **PR 模板预案**：危机声明、道歉信、整改公告的草稿，提前写好放抽屉里
- [ ] **法律顾问预 retainer**：危机时第一通电话有人接

### 事中应对（24 小时黄金窗口）

- [ ] **第 0-6 小时**：暂停争议玩法，删除最敏感内容（但**不要删除全部历史**，会被解读为"心虚")
- [ ] **第 6-12 小时**：发布**真诚的、不甩锅的**致歉/说明声明，避免"管理疏忽""个别员工"这类话术
- [ ] **第 12-24 小时**：上线**整改后的安全版本**，让公众看到"在行动"
- [ ] **持续**：主动联系媒体记者，提供整改细节，掌握后续叙事
- [ ] **不要做的事**：起诉用户、删评、攻击友媒、找水军洗地——每一条都会放大危机

### 事后复盘（事件平息后 1 个月内）

- [ ] **业务结构调整**：永久下线被定性的玩法，调整收入结构占比
- [ ] **建立"早期预警机制"**：每月扫一次本清单
- [ ] **沉淀"分水岭后的新增长曲线"**：用安全玩法做出新爆款，证明你不依赖灰色
- [ ] **向监管/行业协会主动建联**：成为"被信任的合规标杆"而非"被警告的灰色玩家"

## 每条说明（详解）

### Q-A: IP 与版权
**为什么问这个**：参考"盲勺"——大量未授权 IP 周边被随意打包售卖，一份律师函可以让小商家归零。
**怎么算通过**：每个 IP 都有可追溯的授权链路。
**反模式**："这个 IP 没人会告我"——增长越快越容易被盯上。

### Q-B: 资质与牌照
**为什么问这个**：医疗、教育、金融、出版、直播带货都有明确资质要求，缺一即违法。
**怎么算通过**：合规清单 + 持证人员清单 + 续期日历。
**反模式**：先做起来再补——补不上的时候已经被罚。

### Q-C: 内容尺度
**为什么问这个**：参考"小黄鱼"——擦边操作让一个 NPC 走红，也让整个行业被《人民日报》定调。
**怎么算通过**：内部"红线词清单 + 红线动作清单"已落地培训。
**反模式**：靠"擦边换流量"做核心增长——红利期短，反噬周期长。

### Q-D: 消费陷阱
**为什么问这个**：盲盒、抽奖、预售这类机制天然处于监管灰区，2023 年以来反复被收紧。
**怎么算通过**：定价/抽奖机制经过法务+合规双签。
**反模式**：把概率/赔率做模糊，赌用户和监管都看不懂。

### Q-E: 未成年人保护
**为什么问这个**：未成年人是监管最敏感的红线，一例事故就可能整条产品线被关。
**怎么算通过**：有完整的年龄识别 + 消费限额 + 监护人确认链路。
**反模式**："我们不针对未成年人"——但没有任何拦截机制。

### Q-F: 数据与隐私
**为什么问这个**：个保法 2021 落地以来执法越来越严，且用户敏感度大幅提升。
**怎么算通过**：所有数据收集点有明示授权 + 退出通道 + 删除机制。
**反模式**：用户协议藏几百页，默认勾选。

### Q-Signal: 预警信号
**为什么问这个**：分水岭事件极少"无预兆发生"，往往有 1-2 周的山雨欲来。
**怎么算通过**：团队有专人每日监测 5 个信号源，发现立即上报。
**反模式**：埋头做业务，对外界舆情零感知。

### Q-Plan: 应对预案
**为什么问这个**：危机的第一天往往决定后续 6 个月的命运。临时反应几乎注定出错，预案才能救命。
**怎么算通过**：所有 PR/法律/产品/客服文档已写好，演练过至少 1 次。
**反模式**：事到临头才开会想办法。
