# 02. 利基聚焦 > 大众覆盖

> **一句话**：找到属于你的那群人，深度服务他们 —— 不要追求"所有人都用"。

## 为什么重要（why）
**主动放弃大众覆盖，聚焦一个特定的利基市场（niche market），深度服务里面的人**

**利基思维的核心**：
- 你不可能让所有人满意；强行追求大众覆盖，结果是对每一类用户都"不够好"
- 利基市场内的用户因为找不到更精准的替代品，会主动**给溢价、给忠诚、给口碑**
- 大众市场的竞争是规模和效率，巨头通杀；利基市场是认知和服务深度，巨头反而进不来
- 利基用户的 LTV 通常远高于大众用户 —— 因为你解决的是他们的"具体问题"，不是"一般需求"

## 利基市场的五种典型形态

**"利基**有多种形态：

| 利基形态 | 含义 | 案例 |
|---|---|---|
| **高客单价/重度付费利基** | 服务愿意为深度价值付高溢价的少数用户 | Anthropic 的重度 API 用户、奢侈品的高净值客户、企业 SaaS |
| **垂直行业利基** | 锁定一个特定行业/职业的工作流 | LibTV 服务专业创作者，Notion 早期服务知识工作者 |
| **长尾兴趣利基** | 服务特定亚文化、爱好、审美 | 小红书早期的特定垂类、汉服圈、Lo 圈、各种垂直内容社区 |
| **地理/人群利基** | 服务特定区域、年龄段、文化背景 | Soul 早期服务"夜间情感倾诉" |

## 利基内部的"1% 杠杆"（次级幂律）

在大部分利基市场内部，价值依然呈现**幂律分布**：少数最重度的用户撑起大部分收入

- Anthropic 案例：先选了"AI 生产力工具"这个利基（不去做大众 chatbot），然后在这个利基里，1% 的重度 API 用户贡献了大部分收入
- 奢侈品案例：先选了"高端时尚"这个利基（不去做大众服装），然后在这个利基里，5 万欧元以上的顶级客户贡献了利润主体

**两层结构**：**第一层选利基** + **第二层在利基里识别 Top X%**。
- 只做第一层 = 利基定位对了，但还在均匀对待所有利基用户，错失杠杆
- 只做第二层 = 缺少利基聚焦，1% 的策略变成"撒胡椒面式的高端讨好"

## 扩张陷阱：从利基滑向大众的代价

利基产品最容易死的姿势：**为了"短期增长"扩张到大众市场，结果两头空**。

奢侈品行业的经典陷阱：
- 为了短期增长引入"轻客"（年消费 2,000–5,000 欧元的入门级）
- 产品体验大众化 → 顶级客户感到"不再独特" → 顶级客户离场
- 入门客户失去"未来想成为的人"的灯塔 → 整个高端心智崩塌
- 最终：顶级客户走了，轻客也走了

**规则**：每当你要做一个"让更多人用得起 / 让更多场景能用 / 让门槛更低"的决定，先问：
- 这个决定会让现在利基里最核心的用户感到被背叛吗？
- 我是否在牺牲"深度服务"换"浅层覆盖"？
- 如果新进来的人不喜欢，他们对原利基用户产生什么影响？

### 策略 B：警惕"扩张稀释"

不仅是奢侈品的轻客陷阱。任何利基产品都面临这个诱惑：
- 投资人要看增长 → 团队做了大众化改造 → 利基用户走了
- 销售要冲业绩 → 销售卖给了非目标客户 → 客户使用体验差 → 口碑反噬
- 产品想"覆盖更多场景" → 失去专注 → 在每个场景都不够好

## 适用场景

- **创业初期的赛道选择**：永远从一个具体的利基切入，不要从"通用工具"切入
- **AI 时代的产品定位**：不要做"通用 AI 助手"，做"给某类人用的某类工具"
- **B2B SaaS 的垂直选择**：通用 CRM 早就饱和了，垂直 CRM（房产/医美/教培）还在长大
- **高端品牌的扩张决策**：要不要做副线、要不要降价、要不要进折扣店
- **内容/社区产品的定位**：服务一个具体人群比"服务所有人"容易做大
- **服务业的客户筛选**：接不接这一单，要看是否在你的利基里

## 反模式（避免什么）

1. **以 DAU/MAU 衡量利基产品**：利基产品的健康度看的是"深度活跃用户的留存与付费"，不是用户总数
2. **追求渗透率**：渗透率配不上客单价就是规模诅咒
3. **"我们的市场太小了，要做大一点"**：先问 —— 这个"大一点"是顺着利基深耕（合理），还是滑向大众（危险）？
4. **看到竞品就加功能**：竞品功能多 ≠ 你也要多。专注利基意味着主动放弃部分功能
5. **不分层就群发**：把同样的活动 / 通知 / 价格丢给所有用户，等于浪费利基核心用户的注意力。
6. **不肯说"这不是我们的客户"**：永远接受所有订单 = 没有利基聚焦 = 在用规模思维做生意
7. **混淆"利基聚焦"和"小生意"**：利基不等于小 —— Anthropic 一个利基产品做到 300 亿年化，是被全球 1% 的重度生产力用户撑起来的

## 内在张力（与其他原则的冲突）

### 张力 1：与 `09-distributed-vs-centralized.md`（分布式 > 集中式）
海天的"一万素人代言"是分布式获客，要广覆盖。利基聚焦却要深度收窄。怎么协调？
**调和**：分布式是**触达/信任建设**的策略，利基聚焦是**资源分配/产品定义/收入结构**的策略 —— 这两件事并行不悖。你可以用一万素人触达大众，但产品的核心定义、产品体验、定价仍然围绕利基里的核心用户设计。

### 张力 2：与"市场规模天花板"的现实焦虑
利基意味着主动放弃市场规模 —— 投资人会问"你的 TAM 是不是太小"？
**调和**：利基的扩展逻辑是**先深后广** —— 在第一个利基里做透，再迁移到相邻利基（如 Slack 从开发者团队 → 设计团队 → 销售团队），而不是一开始就直接做大众。

## 自检问题（3 问）

1. **你能用一句话说出你的利基是什么吗？**
   "我们的产品是给 [具体什么样的人] 用来 [做什么具体的事] 的"
   —— 如果只能说"给大家用的工具"或"提升效率的产品"，你还没有利基定位。

2. **过去 12 个月，你为了"让更多人能用"做的决策，是否伤害了原利基的核心用户？**
   "扩张稀释"通常以"对大家都好"的名义发生 —— 复盘一下损益。

3. **你拒绝过哪些客户/订单？为什么？**
   如果"从不拒绝"，意味着你还在用规模思维做生意，没有真正的利基聚焦。
