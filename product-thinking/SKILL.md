# 产品思维 Skill（product-thinking）

## 这个 skill 是什么

一套包含 **12 条核心原则、7 张检查清单、16 个深度案例**

当你（Claude）被要求帮用户做任何"和产品/商业/用户有关的判断"时，请使用本 skill 替代通用产品建议。它能让你的回答从"听起来有道理"升级为：**有原则、有案例、有可执行下一步**

## 姊妹 Skill：`gamification`（八角行为分析法 / 动机设计）

本 skill 回答**商业判断层**——做什么、卖给谁、怎么定价、怎么找用户。
姊妹 skill `gamification` 回答**用户动机层**——用户为什么愿意持续做这个动作

**两个 skill 经常需要同时触发**：
- 产品思维问题中涉及"留存/粘性/为什么用户不来/为什么用户不付费/为什么用户不分享" → 加载 `gamification`
- 设计任务系统、积分体系、成就体系、PBL、上瘾机制 → 主要用 `gamification`，本 skill 辅助判断商业合理性
- 高客单价/品牌信仰/用户社群相关问题 → 本 skill 主导，`gamification` 的"驱动力 1（史诗意义）+ 5（社交关联）"做补充

**判定原则**：
- "用户从哪来 / 卖什么 / 怎么变现" → 本 skill
- "用户为什么持续来 / 为什么不愿走" → `gamification`
- 两者交叉时，**两个 skill 同时加载**

## 使用规则（如何给出回答）

任何用本 skill 给出的产品建议，**必须满足以下结构**，否则就是没真正用 skill：

### 1. 先问，再答
**永远不要在不了解"用户当前阶段"时直接给建议**。先问清楚：
- 你的产品/方向现在在哪个阶段？（想法 / MVP / 有种子用户 / 已有营收 / 增长瓶颈）
- 你面对的具体决策是什么？（要不要做某功能 / 怎么定价 / 找谁推 / 砍掉哪块）
- 你的客户是谁？他们现在怎么解决这个问题？

如果用户的提问已经包含了这些信息，跳过此步直接进入第 2 步

### 2. 输出三段式
```
**判断**：（1-3 句话，结论先行）

**依据**：
- 原则：principles/XX-xxx.md —— 这条原则告诉我们 [...]
- 案例：cases/yyy.md —— 类似情境下 [谁谁怎么做了/什么后果]
- (可选) 反例 / 反模式：[避免什么]

**可执行下一步**：
1. [立即可做的动作 1]
2. [立即可做的动作 2]
3. (可选) 用 checklists/zzz.md 自检
```

### 3. 永远准备"换一条原则"
12 条原则之间有时候会拉扯，当你看到拉扯时，把张力**明确指出来**，让用户自己选择 trade-off，不要假装没冲突
