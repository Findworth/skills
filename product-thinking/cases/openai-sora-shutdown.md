# OpenAI 关停 Sora：算力 ROI 与「有趣 vs 有用」的取舍

> **TL;DR**：在 IPO 前夕，OpenAI 把高度消耗算力但只能换来"点赞转发"的 Sora 砍掉，把资源全部押注会持续付费的企业向 Codex；消费级的"有趣"打不过企业级的"有用"。

## 关键事实
- 时间节点：OpenAI 刚完成 110 亿美元融资，估值推至 7300 亿美元，进入 IPO 倒计时窗口。
- Sora 是生成视频产品，单次调用消耗的 GPU 算力可顶 ChatGPT 回答几十个问题。
- 应用主管 Fidji Simo 在全员会上明确：停止被"支线任务"分散，激进转向编码与企业客户。
- Codex 今年用户增长 3 倍、使用量增长 5 倍、周活突破 200 万；OpenAI 上月并购开发者工具公司 Astral，整建制并入 Codex 团队。
- 对照数据：Anthropic 年化收入 190 亿美元，约 80% 来自企业客户；仅 2 月新增 60 亿美元，几乎全部来自 Claude Code。
- 商业判断：企业客户会续费、会扩容；消费级用户只会点赞和转发，不一定掏钱。
- 决策本质：把算力从 Sora 抽走重新分配给 Codex，是一次"在投资人审视下"的资源再分配。

## 体现的产品思维原则
- **principles/04-certainty-over-novelty.md** —— Sora 提供"有趣的可能性"，Codex 提供"企业付费的确定性"；当二者抢算力时，确定性永远赢。
- **principles/10-validation-and-msu.md** —— Codex 用户量、使用量、收入占比都是被市场验证过的硬数据；Sora 缺少同等强度的付费证据，所以被砍。

## 可迁移的启示
- 资源稀缺时，"未被验证的可能性"应当让位给"已被验证的现金流"，无论前者多么性感。
- 评估一个产品的去留，不要只看用户量，要看「单位资源换回的可付费需求」——Sora 烧的是 GPU，Codex 烧的也是 GPU，但后者每一度电换回的是企业续费合同。
- 公司处于关键资本节点（IPO、融资、上市后第一财报）时，会被迫做出"长期友好但情感残忍"的决策；提前预判这个窗口能让团队少受冲击。
- 区分"传播指标"与"付费指标"：转发、点赞、热搜是免费的喝彩；续费、扩容、加购才是真实的票。
- 不要被"创始人偏爱的产品"绑架决策——Sora 当年是 OpenAI 的明星演示，砍它需要的是组织理性。

## 误用警告
- 不要据此推论"所有 ToC 产品都不值得做"——Sora 失败的是"高算力 + 弱付费"的组合，不是 ToC 本身。
- OpenAI 的算力极度稀缺，这是它做取舍的前提；如果你的边际成本接近零（纯软件 / 已有闲置算力），保留"有趣"的探索性产品反而是合理的护城河。
- "企业客户更值钱"在 SaaS / AI 工具语境下成立，但在内容、社交、消费品里完全不适用——别把"Codex 打败 Sora"的结论平移到错的赛道。
