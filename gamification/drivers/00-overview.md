# 八角行为分析法（Octalysis）总览

> **一句话**：所有让人持续投入的行为，背后必然有 1-3 条核心驱动力在起作用；找出哪条边在驱动、哪条边在缺失，是设计的起点

## 八角的来源

周郁凯（Yu-kai Chou）在分析了上千款让人沉迷的产品（从游戏到 Facebook、维基百科、推特、电商）后，归纳出**人类做任何长期投入行为，背后只有 8 种核心驱动力**。把它们排成八边形：

```
                  1. 史诗意义与使命感
                      （白帽 · 右脑）
        8. 亏损与逃避心            2. 进步与成就感
        （黑帽 · 左脑）            （白帽 · 左脑）

   7. 未知性与好奇心                    3. 创意授权与反馈
   （黑帽 · 右脑）                       （白帽 · 右脑）

        6. 稀缺性与渴望            4. 所有权与拥有感
        （黑帽 · 左脑）            （白帽 · 左脑）
                  5. 社交影响与关联性
                      （中性 · 右脑）
```

**两条对称轴**：
- **上 vs 下**：上半（1/2/3）是白帽—激发积极、长效、有意义；下半（6/7/8）是黑帽—激发短效、有效但消耗
- **左 vs 右**：左半（2/4/6/8）是左脑—外在动机驱动（目标、物品、奖励）；右半（1/3/5/7）是右脑—内在动机驱动（创造、社交、好奇）

## 诊断流程：用八角分析一个产品

### Step 1. 列出"用户做的所有期望行为"

把用户在你产品里的关键行为列出来：注册、第一次成功、第二次回访、邀请朋友、付费、深度使用、留下内容、推荐他人……

### Step 2. 对每个期望行为问"哪条边在驱动"

| 行为 | 在驱动的核心驱动力 |
|---|---|
| 用户为什么会注册？ | 大概率是 5（朋友在用）+ 1（产品愿景吸引）|
| 用户为什么会完成新手任务？ | 大概率是 2（进度条）+ 7（好奇下一步）|
| 用户为什么会回访？ | 大概率是 5（朋友更新）+ 6（每日任务）+ 7（不知道有什么新内容）|
| 用户为什么会付费？ | 大概率是 4（不想丢失账号）+ 6（限时优惠）+ 8（不付费就损失已积累的）|
| 用户为什么会主动分享？ | 必然是 1（有意义）+ 5（炫耀身份）+ 2（成就感）|

### Step 3. 画出当前八角分布

每条边给 0-10 分，画出当前产品的八边形。**典型问题**：
- "新手期高、长期低" → 1（意义）和 4（拥有感）薄弱
- "用户用一次就走" → 4（没积累拥有感）+ 6（没触发回访）+ 7（没新鲜感）薄弱
- "用得多但不付费" → 4（没构建付费才能拥有的东西）+ 8（不付费没损失）薄弱
- "用得多但不分享" → 1（产品没意义感支撑分享理由）+ 5（没设计自夸按钮）薄弱
- "PBL 元素堆满但用户无感" → 全靠左脑（2/4/6/8）撑场，右脑（1/3/5/7）几乎为 0

### Step 4. 决策：补哪条边

**不是哪条边低就补哪条边**。补边的优先级：

1. **优先补白帽（1/2/3/4）**：长效且不会让用户疲惫
2. **黑帽（6/7/8）作为短期突破**：临门一脚的转化、激活沉睡用户、新版本上线时用，但不能成为骨架
3. **5（社交）必补**：几乎所有 toC 产品都依赖 5 做病毒增长，但要选对模式（攀比 / 师徒 / 归属）
4. **3 + 4 是留存的灵魂**：让用户能创造、有积累，他就不会离开

## 黑白帽组合策略

| 组合 | 用法 | 例子 |
|---|---|---|
| 全白帽 | 长期陪伴型产品（教育、健康、知识社区）| 维基百科、Duolingo |
| 白帽为主 + 黑帽点缀 | 大多数好产品的常态 | Facebook、Notion |
| 全黑帽 | 短期爆款、赌博/抽奖类、一次性活动 | 老虎机、刮刮乐、限时秒杀 |
| 黑帽伪装成白帽 | 危险设计——会让用户在用完后产生厌恶 | 部分氪金手游、过度推送的电商 App |

## 左右脑组合策略

- **不要全靠左脑撑产品**：积分/勋章/排行榜（PBL）全是左脑机制。用户初期觉得新鲜，但一旦没了奖励就会流失（过度理由效应，详见 `fundamentals/left-vs-right-brain.md`）
- **右脑机制是黏性来源**：让用户因为创造（3）、社交（5）、好奇（7）、意义感（1）而留下
- **理想配比**：右脑撑骨架 + 左脑做反馈节奏

## 如何使用本目录

**当你（Claude）面对一个动机设计问题**：
1. 先用本文件做八角诊断，找出"缺哪条边"
2. 加载缺失边对应的 `drivers/0X-xxx.md` 文件，查看具体技巧
3. 同时加载 `fundamentals/` 中相关的元概念，确保推荐的技巧不踩反模式
4. 如果有相似的 case，加载 `cases/` 中的对应案例做证据

**驱动力之间的关系不是孤立的**：
- 1（意义）+ 5（社交）= 形成信仰社群（如苹果、特斯拉粉丝、品牌教徒）
- 2（成就）+ 5（社交）= 形成炫耀机制（如健身房打卡、跑步晒图）
- 3（创意）+ 4（拥有）= 形成 UGC 长期积累（如 Minecraft、Notion、博客）
- 6（稀缺）+ 7（未知）= 形成抽奖/盲盒/扭蛋机制
- 6（稀缺）+ 8（损失）= 形成倒计时优惠的转化压力

## 不要在不诊断的情况下推荐技巧

如果用户问"我的产品怎么提升留存"，**先做八角诊断**再推荐。直接说"加个进度条吧"是把驱动力 2 当成万能药，往往用错。
