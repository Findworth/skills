# 左脑 vs 右脑：内在动机与外在动机

> **一句话**：左脑动机靠外部奖励驱动（目标、物品、积分），右脑动机靠内在感受驱动（创造、社交、好奇）；好产品以右脑为骨架，因为**外在奖励会侵蚀内在动机**

## 定义

### 左脑核心驱动力（外在动机）

与逻辑、计算、所有权联系：
- 驱动力 2：进步与成就感（追求目标）
- 驱动力 4：所有权与拥有感（追求物品）
- 驱动力 6：稀缺性与渴望（追求稀有）
- 驱动力 8：亏损与逃避心（避免失去）

**特征**：
- 依赖**外在动机**——你做事是因为想得到东西（奖励、地位、积分、避免损失）
- 行为可被精确预测和测量
- 短期内有效——给什么奖励，行为就出现
- 一旦停止奖励，行为很快消失

### 右脑核心驱动力（内在动机）

专注于创造力、自我表达、社会动力学：
- 驱动力 1：史诗意义与使命感（追求意义）
- 驱动力 3：创意授权与反馈（追求表达）
- 驱动力 5：社交影响与关联性（追求关系）
- 驱动力 7：未知性与好奇心（追求探索）

**特征**：
- **内在动机**——做事本身就是奖励，不需要外部刺激
- 难以量化和预测
- 启动较慢，但极具黏性
- 即使没有外部奖励也能持续

## 关键陷阱：过度理由效应

这是本文件最重要的概念——也是大多数 PBL 设计失败的根本原因

### 过度理由效应（Overjustification Effect）

**原本因为兴趣（内在动机）做某事的人，一旦获得了外部奖励，会把行为归因于外部奖励。一旦奖励停止，他们做这件事的意愿会降到比之前更低**

**经典实验**：
1. 一群孩子本来喜欢画画（内在动机）
2. 给他们每画一幅画发一个金星贴纸（外在奖励）
3. 一段时间后停止发贴纸
4. **结果**：孩子们画画的频率降到了**比实验开始前还低**

### 在产品设计里的灾难性表现

源材料的总结：
> 许多企业的设计往往都以外在动机因素为主，比如完成任务后提供奖励。然而，许多研究表明**外在动机会削弱内在动机**。一旦公司停止提供外在动机，**用户动机会骤降到比之前更低的程度**

具体场景：
- 用户原本喜欢在你的产品上分享内容（内在动机）→ 你为分享行为发积分 → 用户开始为积分而分享 → 你停止发积分 → 用户分享意愿低于初始水平
- 用户原本喜欢健身（内在动机）→ App 给打卡发现金 → 用户为现金而打卡 → 现金停了 → 用户不去健身了，反而觉得"白干"
- 用户原本喜欢在论坛回答问题（内在动机）→ 平台开始按回答数给奖金 → 高质量回答减少、灌水回答增加，整个社区氛围崩塌

## 关键原则

源材料的核心建议：
> 对企业来说，设计的体验最好能激发人们的**右脑核心驱动力**，让产品本身就充满乐趣和奖励，这样用户可以持续享受和参与到活动中。**好的动机往往是有黏性的**

具体执行：

### 原则 1：右脑撑骨架

产品的核心吸引力必须来自驱动力 1/3/5/7：
- 用户做这件事，是因为**它本身有意义**（1）
- 用户做这件事，是因为**他能创造独特的东西**（3）
- 用户做这件事，是因为**他能和别人产生连接**（5）
- 用户做这件事，是因为**他好奇下一步**（7）

如果以上四条都没有，**任何 PBL 都救不了你**。

### 原则 2：左脑做反馈节奏

驱动力 2/4/6/8 不是设计的起点，而是给右脑驱动力做"反馈"：
- 用户在创造（3）→ 进度条让他看到成果（2）
- 用户在社交（5）→ 朋友的点赞给他即时反馈（5+2）
- 用户在探索（7）→ 偶尔解锁新内容（7+2）

### 原则 3：永远警惕外部奖励侵蚀内部动机

每当你想加奖励/积分/优惠时，先问：
- **用户做这件事原本就有内在动机吗？**
  - 有 → 加奖励反而会破坏。考虑用"反馈"而非"奖励"
  - 没有 → 那需要先解决"为什么用户要做这件事"——加奖励只是花钱买短期数据，停了就归零

## 内在动机重新激发的方法

如果你已经因为过度理由效应破坏了用户的内在动机：
1. **重新讲意义**：让用户重新理解他做这件事为什么有价值
2. **改"奖励"为"反馈"**：把"给你积分"改成"你的贡献让 X 个人受益了"
3. **降低奖励的可预测性**：从"每次都给"改成"偶尔给"，让用户重新关注行为本身
4. **强化社交关联**：让用户的行为被看见、被认可，激发驱动力 5
5. **降低/取消金钱奖励**：如果你之前用了金钱奖励，把金钱降到象征性水平（恢复内在动机会很慢，但是必经之路）

## 不同产品类型的左右脑配比

| 产品类型 | 推荐配比 | 原因 |
|---|---|---|
| 创作工具 | 右脑 80% / 左脑 20% | 创造本身就是动机 |
| 学习产品 | 右脑 60% / 左脑 40% | 需要适量进度反馈 |
| 健身/打卡 | 右脑 50% / 左脑 50% | 内在动机有限，需要外在加持 |
| 电商 | 右脑 30% / 左脑 70% | 交易本质偏左脑 |
| 抽奖/盲盒 | 左脑 90% | 短期爆款不需要长期动机 |
| 高端品牌 | 右脑 90% | 意义、身份、归属是核心 |

## 反模式

1. **全部 PBL**：积分 + 勋章 + 排行榜 + 等级 + 任务系统 + 每日签到 + 优惠券——左脑机制堆满，右脑驱动力为 0，看似很热闹实际空心
2. **金钱奖励代替设计**：花钱买行为——一旦停就崩
3. **奖励大于行为价值**：用户感觉是为奖励而做，不是为事情本身
4. **以为内在动机会自动出现**：右脑驱动力需要主动设计，不会因为产品"功能好"就出现

## 自检问题

1. 如果**你的产品明天取消所有奖励/积分/优惠**，**还有多少用户会留下来**？这个数字就是你右脑驱动力的真实水平。
2. 你的用户来你产品做事时，**主要是为了"得到什么"还是为了"体验什么"**？
3. 你最近一次加 PBL 元素，是为了**反馈现有的内在动机**，还是**替代缺失的内在动机**？后者是危险信号。
