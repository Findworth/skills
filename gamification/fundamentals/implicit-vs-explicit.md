# 内隐游戏化 vs 外显游戏化

> **一句话**：外显游戏化看起来就像游戏（用户承认在玩），内隐游戏化用户察觉不到但已被深度激励——多数严肃产品该选内隐

## 定义

### 外显游戏化（Explicit Gamification）

应用看起来就是游戏——**用户会承认他们是在玩游戏**

典型例子：
- 麦当劳的《大富翁》营销活动（所有人都知道在玩游戏，目的是让人多吃薯条）
- 银行 App 的"理财大冒险"小游戏
- 信用卡 App 里抽奖、转盘
- 大量营销互动 H5

**优点**：
- 产品本身变得好玩
- 设计师有更多发挥创意的自由
- 用户的"游戏心态"被激活，对得失更宽容

**缺点**：
- 对企业、银行、医疗、制造等严肃用户来说：**幼稚、不严肃、甚至分散注意力**
- 一些企业管理者一看到图形化游戏就反感
- 容易让产品显得不专业

### 内隐游戏化（Implicit Gamification）

设计中包含大量游戏元素，但**用户察觉不到这是游戏**——他们以为自己只是在正常用产品

典型例子：
- **LinkedIn 的进度条**：大多数人不会觉得这是在玩游戏，但进度条平缓激励用户填完资料
- **维基百科的编辑按钮**：背后是意义驱动力，但用户不会说"我在玩游戏"
- **eBay 的竞拍系统**：竞争性投标 + 反馈系统，本质是游戏化但表现为商业行为
- **OPower 的社会比较**：电费账单上印"你的邻居用电比你少 20%"——本质是社会认同驱动力
- **Woot! 的限时秒杀**：未知性 + 稀缺性，但用户以为是在购物

**优点**：
- 严肃用户接受度高
- 不显得幼稚
- 长期粘性更强（用户不会觉得"游戏不好玩了我就走"）

**缺点**：
- 设计难度更高（要藏起来）
- 创意空间相对受限
- 不容易做出短期爆款效果

## 在内隐游戏化里，PBL 仍然广泛存在

内隐游戏化不等于"没有 PBL"——它只是把 PBL **藏在自然的产品流程里**：
- 信用分（积分系统的内隐形式）
- 微信运动步数（成就 + 社交比较的内隐形式）
- 健身环的圆环填满（进度条的内隐形式）
- 知乎的赞同数（社交财富的内隐形式）

**关键区别**：用户不会因为这些"PBL"才使用产品；这些 PBL **只是放大了产品本身的内在动机**。

## 如何选择：外显 or 内隐

| 场景 | 推荐 | 原因 |
|---|---|---|
| 营销活动 / 拉新 | 外显 | 一次性触达，需要瞬间吸引力 |
| 银行 / 保险 / 医疗 | 内隐 | 严肃用户，外显会显得不专业 |
| 儿童 / 教育产品 | 外显 | 用户预期就是有趣的体验 |
| 企业 SaaS / B2B | 内隐 | CFO 看到表盘做成游戏会拒绝采购 |
| C 端工具（笔记、AI、效率） | 内隐 | 用户来解决任务，不来玩 |
| 社交 / 内容平台 | 内隐 | 沉浸感比游戏感更重要 |
| 健身 / 学习 / 习惯养成 | 内隐为主，外显点缀 | 长期黏性靠内隐，短期激活可加点外显 |
| 游戏 / 娱乐产品 | 外显 | 本来就是游戏 |

## 误判信号

### 用了内隐但效果像外显
- 表现：用户开始吐槽"为什么我用银行 App 还要打卡领积分"
- 原因：你以为内隐，其实做得太显眼
- 修复：把"任务系统"重新包装为自然的产品流程

### 用了外显但用户不进入游戏心态
- 表现：营销 H5 投放出去转化极低
- 原因：用户没意识到这是游戏，或游戏体验太差
- 修复：要么强化游戏感（更有趣的视觉/玩法），要么转为内隐机制

## 严肃游戏 / 广告游戏：游戏化的延伸定义

源材料还提到两个相关概念：

**严肃游戏（Serious Games）**：维基百科定义为"设计初衷不止是娱乐的游戏"——比如军事训练模拟、医疗培训游戏、灾难演习游戏

**广告游戏（Advergames）**：以某种方式为产品/服务做广告的视频游戏——比如品牌定制的互动 H5、视频网站的"打鸭子"广告

**作者的观点**：在以人为本设计的视角下，**严肃游戏和广告游戏都应该列入游戏化范畴**——它们都是利用游戏设计实现非游戏的生产性结果

## 反模式

1. **B 端产品强加外显游戏化**：在 ERP 系统里加"打怪兽"——CIO 拒绝采购
2. **C 端工具藏太深**：用户感受不到任何反馈和激励——内隐过头变成"没有"
3. **混搭得不伦不类**：界面 90% 严肃 + 10% 突兀的游戏化弹窗——两边都不讨好
4. **以为加了 PBL 就是游戏化**：忽略了 PBL 只是表象（详见 `surface-vs-deep-design.md`）
