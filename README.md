## gamification

对 [美] 周郁凯（Yu-kai Chou）著、杨国庆译《游戏化实战》的沉淀。

游戏化的本质是动机设计，不是往产品上堆积分、勋章、排行榜。周郁凯提出的八角行为分析法（Octalysis）认为：人会长期投入一件事，背后只有八种核心驱动力；把它们排成八边形，缺哪条边、滥哪条边，比「再加一套任务系统」更先该看清。

八条边：

1. 史诗意义与使命感：觉得自己在参与比个人更大的事
2. 进步与成就感：看得见进展，能克服挑战
3. 创意授权与反馈：能创造、试错，并立刻看到结果
4. 所有权与拥有感：对账号、物品、数据产生归属
5. 社交影响与关联性：攀比、师徒、认同、归属
6. 稀缺性与渴望：限时、限量、够不着
7. 未知性与好奇心：下一步会怎样，事先不知道
8. 亏损与逃避心：不愿承认白做，不愿失去已得

1–4 偏白帽，激发长效、有意义的投入；6–8 偏黑帽，短期有效但会消耗；第 5 条居中。本 skill 用来诊断「用户为什么没感觉、留不住、不愿再来」，而不是给运营套路。

## okr-writing

本 skill 做两件事：

- 如何写：先定 O（目标，定性、有方向），再由 O 推出 KR（关键结果，定量、可验证），而不是把待办事项拼成一套假目标
- 什么是好的 OKR：O 鼓舞人心且不是任务；KR 是结果证据而不是「上线了什么」；每个 O 配 3–5 个 KR，能覆盖目标、有优先级，而不是面面俱到

## outsourcing-evaluation

本 skill 用来把判断做清楚：

- 先过红线：付款不可接受、合规/版权触线、核心人不可替代且排不出、需求两轮对齐后仍说不清——任一条直接不接
- 再走六维：技术能否做、人与排期是否够、需求边界清不清、跟主线能不能互借力、最坏情况承不承受、商业上值不值得（含机会成本）
- 结论必须明确：接 / 有条件接 / 需更多信息 / 不接，并写出依据，而不是一段分析后没有答案

## product-thinking

本 skill 是我在日常生活里对新闻、公司和产品动作的思考，用产品视角思考的沉淀：这件事到底卖给谁、用户为什么付钱、差异化是重新定义品类还是在原赛道较劲、信任从哪来、验证有没有走到钱包

所谓产品思维，就是把「发生了什么」翻译成「对做一个产品意味着什么」——先给判断，再落到原则和可对照的案例，而不是听起来都对的万能建议。它回答做什么、卖给谁、怎么变现；用户为什么愿意持续参与，交给姊妹 skill `gamification`

## startup-antipatterns

本 skill 是一套创业失败的反模式诊断：7 种反复出现的死法（幻觉、烧钱、内斗、被碾压、次品、踩线、算账不过），以及它们如何连环触发。用来给「还行但增长不动」「用户说好但不付钱」这类早期信号起一个具体的名字，而不是加油式鸡汤。
