# 🔮 THE HALLUCINATION（幻觉）

> **致死原因：** No Market Need / 无市场需求
> **一句话：** Building for a customer that does not exist / 在沙漠里盖大教堂，相信信徒会来
> **数据：** 189 家公司，11.6%，烧掉 $14.2B，中位寿命 3 年
> **重灾区：** Communication Services（78 起）——做协作、做即时通讯，解决用户其实早已绕过去的问题

## The Pattern（模式）

幻觉的特征是"温和地、缓慢地、不发声地"杀死你。没有戏剧性的失败时刻，只有一连串"差一点就转化"的对话、永远不扩张的 pilot、注册但不再回来的用户。

它从最无辜的地方开始：你识别出某件"似乎效率不高"的事，找几个人聊，他们礼貌地点头说"是该改进"。你把礼貌当验证。中位 3 年寿命揭示了这种陷阱的阴险——你可以融钱、做产品、扩团队、运营好几年，而那个根本真相一直被遮蔽：**没有人真的需要改变自己的行为来用你建的东西**

## The Mechanics（四个阶段）

| 阶段 | 现象 | 关键标志 |
|---|---|---|
| **Stage 1：验证幻觉** | 客户访谈中所有人都点头，说"挺有意思" | 你把礼貌当需求，把"假设兴趣"当真实痛点。可能拿到 LOI 或 pilot 协议，但没人需要改预算或工作流。 |
| **Stage 2：上线悖论** | 产品上线，注册数据看起来还行，但激活率诡异 | 用户不回来，sales cycle 无限拉长。你怪文案、怪定价、怪功能，**就是不质疑核心假设** |
| **Stage 3：Pivot 旋转木马** | 围绕已经做出来的解决方案不断改 | 加功能、换目标人群、调整定位。每次 pivot 买 6 个月的跑道和希望 |
| **Stage 4：终末期** | 资本和叙事可信度同时耗尽 | Quibi 两年烧掉 $1.75B 就是因为：没有任何执行卓越能弥补"做了人们不要的东西" |

**可挽救窗口：** 仅在 Stage 1 或 Stage 2 早期。这时你还有资源去**重新想象问题**——不是重新想象解决方案。

## The Cognitive Trap（认知陷阱）

**主要陷阱是确认偏差。** 一旦你承诺了一个想法，所有模糊的信号都被解读为验证：
- 接受会议的潜客 = 兴趣证据
- 注册但不回来的用户 = 还算"获取"
- 沉没成本让你越来越难承认地基错了

**解决方案导向思维**（工程师文化推崇的）在这里变成毒药——你太专注于把东西做漂亮，从来没有停下来验证它"不存在"是不是真的会让任何人难受。

**对聪明的、融到钱的创始人来说尤其隐形**，因为：
- 他们能讲出一套逻辑解释为什么这个问题应该重要
- 他们有足够资本把自己和即时市场反馈隔离
- **投资人因为已经投钱了，变成幻觉的共谋**——他们宁愿相信是"执行问题"也不愿承认是"基本面失败"

## The 7 Red Flags（红色信号）

如果以下任何一条听起来像你，警告灯应该亮起：

1. 客户访谈持续以"听起来挺有意思，保持联系"结尾，**没人问什么时候可以开始用，也没人掏信用卡**。
2. 你解释这个问题为什么重要的 slide 数量，比那些**真的改了工作流来用你产品的用户数量**还多。
3. 你的销售管道里全是**永恒 pilot 阶段**的机会——客户愿意试，但永远不愿买或扩展。
4. 你发现自己在 pitch 之前要先教育客户为什么应该 care——你的 pitch 已经演化成一场"为什么你该在乎这件事"的科普讲座。
5. 用户激活和留存数据糟糕，但你一直怪 onboarding 摩擦、功能缺口、UI 问题——**就是不质疑用户为什么要回来**。
6. 你丢单的时候，客户反对的从来不是价格或功能，而是**时机、预算、优先级**——这些都是"这事不重要到值得行动"的礼貌说法。
7. 团队花在"产品应该做什么"的辩论时间，远多于"现有用户实际在用什么"的分析——因为根本没有足够使用数据来支撑后一个对话。

## The Assessment Question（自评问题）

> **当潜在客户听到你的产品时，在你不催促的情况下，接下来会发生什么？**

| 等级 | 回答 |
|---|---|
| 🟢 **safe（0 分）** | 他们立刻问什么时候可以开始用、多少钱、怎么 onboard 团队。话题转向落地和实施，不需要我说服他们为什么需要。 |
| 🟡 **caution（1 分）** | 他们表示有兴趣、想了解更多、安排后续会议或同意 pilot。有 engagement，但**需要我持续在场**推动并解释价值。 |
| 🔴 **danger（2 分）** | 他们说"听起来挺有意思"、"保持联系"、"几个月后再看看"。**对话礼貌地结束，没有不依赖我跟进的具体下一步**。 |

## 链式反应（HALLUCINATION 触发什么）

| 下一个反模式 | 怎么触发 |
|---|---|
| 🔥 **BONFIRE** | 没有真实需求 → 达不到下一轮所需的增长指标 → 烧光储备试图制造永远不会有机出现的 traction |
| 📉 **MATH PROBLEM** | 你在解决用户其实没那么急的问题 → CAC 暴涨而 LTV 暴跌 → 你在付钱说服别人"你有问题"，经济上不可持续 |
| 🏴 **CRUSHED** | 你为想象中的客户造东西 → 对手发现真实需求并用真实用户迭代 → 等你认出真问题时，对手已拥有解决方案空间 |
| 🍋 **LEMON** | 缺乏真实市场反馈 → 产品开发脱离现实 → 基于假设而非使用数据加功能 → 制造出没有用户需要的技术复杂度 |

## 经典案例

- **Quibi** — 两年烧 $1.75B。问题不在执行，在于：**没人真的需要 10 分钟的高制作短剧**。
