# 复盘输出模板

复盘完成后，按此模板输出标准化复盘文档。

---

## 模板

```markdown
# [周期] OKR 复盘 — [姓名/部门]
**复盘日期**：[日期]

---

## 一、整体达成概览

| O | 达成率 | 评级 |
|----|--------|------|
| O1: [表述] | 0.X | |
| O2: [表述] | 0.X | |
| O3: [表述] | 0.X | |
| **整体** | **0.X** | |

---

## 二、逐条评分明细

### O1：[表述]

| KR | 目标值 | 实际值 | 达成率 | 备注 |
|-----|--------|--------|--------|------|
| KR1: [表述] | | | | |
| KR2: [表述] | | | | |
| KR3: [表述] | | | | |

### O2：[表述]
[同上格式]

---

## 三、10 维度回顾（精简）

### OKR 本身质量
1. O 是否合理：[是/否，为什么]
2. KR 是否覆盖 O：[是/否，哪里漏了]
3. KR 量化标准是否合适：[是/否，具体问题]
4. 是否有 KR 未覆盖的业务：[有/无]

### 过程与执行
5. 进展顺利/遇到问题：[简述]
6. 推进中的关键思考：[1-3 条]

### 支撑关系
7. 对年度/上级 OKR 的支撑：[是/否，具体贡献]

### 边界与额外
8. OKR 之外的重要工作：[列出]
9. 意外收获或损失：[列出]

### 未来导向
10. 对下个周期的影响：[简述]

---

## 四、Keep / Change / Stop / Start

### Keep（继续保持）
- [做法 1]
- [做法 2]

### Change（需要改变）
- [做法 1] → 改为 [新做法]

### Stop（停止做）
- [做法 1]

### Start（开始做）
- [新做法 1]

---

## 五、下周期 OKR 方向（初步思路）

- 方向 1：[简述]
- 方向 2：[简述]
```

---

## 使用说明

- **月度复盘**：用精简版——必填项为一（概览）、二（明细）、五（下周期方向）。三和四选填。
- **季度复盘**：完整填写。10 维度可以精简每条为 1-2 句话。
- **年度复盘**：完整填写。10 维度每条至少 3-5 句话，深入分析。
