# 常见错误

## O 的常见问题（3 类）

### 第一类：手段类目标不清晰

**症状**：知道自己的工作具体要做什么，但没考虑清楚**为什么要干、要干到什么程度**。

**表现**：O 写成了"做什么"而非"达成什么"。
- ❌ "完成用户画像系统开发" → 这是手段
- ✅ "让业务团队能基于用户画像做精准触达" → 这才是目标

### 第二类：目标手段类不清晰

**症状**：知道要做成什么程度，但**不了解这方面业务**，所以无从下手。

**表现**：O 的方向是对的，但不知道该用什么手段实现，导致 KR 写不出来或写的很虚。

**应对**：先用场景构建法具象化目标，再倒推手段。

### 第三类：手段目标都不清晰

**症状**：**完全迷茫期**，不知道该干什么、干到什么程度。

**应对**：不要硬写 OKR。先和上级对齐战略意图，或者先做一轮小范围探索，下个周期再正式设 OKR。

## KR 的常见问题（5 类）

### 第 1 类：写成任务清单（最常见）

**症状**：KR 全是要做的动作，做完了也不知道目标达成了没有。

- ❌ "设计并上线 3 个新功能模块" → 动作
- ❌ "完成竞品分析报告覆盖 5 家竞品" → 动作
- ✅ "3 个新功能上线后，核心功能月活跃用户数提升到 1000 万" → 结果

**改写方法**：每个 KR 后面加一句"……从而使得______"，填空就是真正的 KR。

### 第 2 类：量化浅薄

**症状**：KR 量化了，但量化指标没有触及本质。量化的方式不能代表这个 KR 真正的完成。

**经典案例**：
- ❌ "未来 7 天每天都吃 3 顿饭" → 每天吃 3 顿不一定不饿，有时 5 顿还饿，有时 2 顿就够了
- ✅ "本周感到饥饿的时间不超过 10 小时" → 抓住了"饱腹感"的本质

**识别方法**：问自己——"即使这个数字达到了，O 就真的实现了吗？"如果答案是有疑虑的，说明量化浅薄了。

**纠正方法**：不要简单套用"完成多少 XX"的模板，而是追问：**这个 KR 真正要衡量的是什么？** 然后找最能代表那个东西的指标。

### 第 3 类：方向太小

**症状**：KR 的切入角度过于狭窄，像一个月度任务而非季度/年度目标。过度追求某个具体成果的数量，或者执着于将一个困难任务完成多次。

**经典案例**：
- O：提升产品的市场竞争力，成为所在领域的领先者
- ❌ KR：设计并上线 3 个新功能模块 → 上线功能只是交付，无法衡量是否提升了竞争力
- ✅ KR：核心功能的月活跃用户数提升到 1000 万 → 用结果指标来验证竞争力

**判断方法**：这个 KR 的达成，是一个月的努力还是需要一个季度/一年的努力？如果一个月就能搞定，方向就太小了。

**年度 KR 尤其容易犯这个错误**——因为跨度太长反而不敢设大目标，不自觉地用月度 KR 的思路来写，做出一些"拿得出手的阶段性成果"就满足了。

### 第 4 类：量化指标不可验证

**症状**：KR 的说法看起来有数字，但实际上无法客观验证。

- ❌ "用户体验显著提升" → 什么叫"显著"？
- ❌ "团队能力明显增强" → 怎么证明？
- ✅ "用户 NPS 从 30 提升到 45" → 可以验证

### 第 5 类：KR 数量不当或覆盖不全

**症状**：
- KR 太少（1-2 个）：只覆盖了 O 的某一面，漏了重要维度
- KR 太多（6+ 个）：失去了聚焦，等于每个都不重要
- KR 之间没有覆盖 O 的所有关键词/维度

**纠正**：用解析法检查每个 O 的关键词是否都有 KR 覆盖；用验证法检查是否还有重要的评价维度没设 KR。

## 年度 OKR 特有错误

### 量化小气

年度 KR 因为时间周期长，特别容易写得"小气"——不是因为数字小，而是**切入点过于表面和肤浅**。

- ❌ "全年发布 240 篇内容（月均 20 篇）" → 这是把月度工作量 × 12，不是年度目标
- ✅ "建立行业内有影响力的内容阵地，内容驱动线索占比从 10% 提升到 30%" → 年度质变

### 用打分表代替量化

年度 KR 不能出现打分表——打分表用于处理月度/季度 OKR 中的抽象指标，但年度 OKR 必须找到客观直观的量化方式。

### 不确定性没有被充分识别

年度 KR 跨时长、涉及业务多、需要协同的团队多，制定时需要明确：**"有哪些量化指标是无论发生什么也要做到的？"** 找到了锚点指标，剩下的不确定性可以在季度 OKR 中动态调整。

## 错误速查表

| 错误 | 典型表现 | 改正方向 |
|------|---------|---------|
| O 泛化词 | "奠定基础""明确路径" | 选最能准确表达的具体词 |
| KR=任务清单 | "上线 3 个功能""组织 4 次访谈" | 改成结果指标 |
| 量化浅薄 | "每天吃 3 顿饭" | 追问"真正衡量的是什么" |
| 方向太小 | 季度 OKR 写成月度任务粒度 | 升维思考：完成后世界有什么不同 |
| 不可验证 | "显著提升""明显增强" | 改成可客观测量的数字 |
| 数量不当 | 1 个或 7 个 KR | 控制在 3-5 个 |
| KR 漏维 | O 的某些关键词没被覆盖 | 用解析法/验证法反查 |
| 年度小气 | 年度 KR=月度工作量 × 12 | 找质变锚点 |
| 年度打分表 | 年度 KR 用打分表 | 必须纯量化 |
| 先 KR 后 O | 凑任务拼成 OKR | 先 O 后 KR，严格单向 |

## 好 OKR 判断清单

制定完成后，逐条过一遍。以下 18 条检查项覆盖了上文所有常见错误，任何一项无法通过就回去修改。

### O 的检查（5 条）

- [ ] O 是定性表述，不含数字
- [ ] O 读起来让人有"想做"的感觉（月度/季度），或目标本身足够大（年度）
- [ ] 没有"奠定基础""明确路径""提供支持"等泛化词
- [ ] O 是目标而非手段（不是"做什么"，是"达成什么"）
- [ ] 每个 O 之间有明确的区分度，不是同一件事换三个说法

### KR 的检查（7 条）

- [ ] 每个 KR 都有可量化的数字（或可客观验证的标准）
- [ ] 数字衡量的是**结果**，不是动作/产出
- [ ] 量化方式能代表这个 KR 真正完成（没有"量化浅薄"）
- [ ] KR 的切入点粒度匹配周期长度（没有"方向太小"）
- [ ] 每个 KR 可以独立打分/判断是否完成
- [ ] 年度 KR：没有使用打分表，全部客观量化
- [ ] 年度 KR：找到了一些"无论发生什么也要做到"的锚点指标

### 结构检查（3 条）

- [ ] O 的数量在 1-5 个之间
- [ ] 每个 O 配 3-5 个 KR
- [ ] 所有 KR 加在一起能覆盖 O 的完整意图（用解析法或验证法反查）

### 质量检查（3 条）

- [ ] 如果这些 KR 全达成了，O 一定实现了吗？（"KR→O"逻辑检验）
- [ ] 如果只完成了 60-70%，最重要的进展是什么？（"部分达成"检验）
- [ ] 三个月/一年后回来看这个 OKR，会觉得"值得做"吗？（"后悔测试"）

### 快速评分

满分 18 条（O 5 + KR 7 + 结构 3 + 质量 3）。

| 通过数 | 评级 | 建议 |
|--------|------|------|
| 16-18 | 优秀 | 可以直接用 |
| 12-15 | 及格 | 标注有问题的那几条，尽快修改 |
| 8-11 | 不及格 | 重新审视 O 的方向和 KR 的量化 |
| <8 | 严重缺陷 | 从头重新制定，这个 OKR 有根本性问题 |
